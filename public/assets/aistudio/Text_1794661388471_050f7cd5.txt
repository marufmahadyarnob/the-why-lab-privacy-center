9. BILINGUAL TRANSLATION SYSTEM

This is one of the most important features.

Implement a fully functional language switcher.

Languages:

- English (EN)
- Bengali (বাংলা)

Requirements:

- English is the default language.
- Clicking বাংলা changes the entire website into Bengali.
- Clicking EN changes the entire website into English.
- Translate headings, navigation, buttons, descriptions, FAQ, footer, dates, and policy content.
- Do not translate only the main policy text.
- Preserve the selected language while navigating sections.
- Save language preference using localStorage.
- Update the HTML lang attribute appropriately.
- Do not reload the page when switching languages.

Use a centralized translation object in JavaScript.

Example:

translations = {
en: {
title: "Privacy Center",
overview: "Privacy at a Glance"
},
bn: {
title: "প্রাইভেসি সেন্টার",
overview: "এক নজরে গোপনীয়তা নীতি"
}
}

Implement a clean and maintainable translation structure.
